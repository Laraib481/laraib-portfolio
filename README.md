# Developer Portfolio & Verified Credentials Showcase

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Vercel-brightgreen?style=for-the-badge&logo=vercel)](https://laraib-portfolio-seven.vercel.app/)

A modern, interactive Portfolio and Verified Credentials Showcase application built to present computer science coursework, technical certifications, and full-stack projects. It offers an optimized dual-layout experience featuring dynamic vertical-to-horizontal scroll animations on desktop and hardware-accelerated touch swipe behavior on mobile devices.

🌐 **Live Demo:** [https://laraib-portfolio-seven.vercel.app/](https://laraib-portfolio-seven.vercel.app/)

---

## 🛠️ Tech Stack & Key Features

* **Tech Stack:** React, Vite, Tailwind CSS, Framer Motion, Lucide React.
* **Interactive Live Previews:** Built-in PDF viewer modal allowing visitors to inspect official certificate documents directly without leaving the app.
* **Dual Responsive Layout:** Smooth Framer Motion scroll animations for desktop viewport combined with native touch momentum swipe (`snap-x`) for mobile efficiency.
* **Dynamic UI Elements:** Marquee announcement banners and customizable certificate cards with metadata tags and direct external credential links.

## 🚀 React + Vite Setup

This template provides a minimal setup to get React working in Vite with HMR and some Oxlint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

### React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

### Expanding the Oxlint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and Oxlint's TypeScript related rules in your project.
